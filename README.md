# Ecommerce-Sales-Analysis-Excel
Interactive E-commerce Sales Analysis Dashboard built with Excel, Power Query, Power Pivot, and DAX.
🚀 **E-Commerce Sales Analysis | Excel & Power Pivot Project**

I'm excited to share my latest Data Analytics project, where I transformed raw e-commerce data into interactive dashboards to analyze sales performance, customer behavior, product performance, and returns.

📊 **Project Overview**

The dataset contains over 53,000 records, covering orders, customers, products, sales channels, and returns.

🛠️ **Tools & Technologies Used**

- Microsoft Excel
- Power Query
- Power Pivot
- Data Modeling
- DAX (Data Analysis Expressions)
- PivotTables & PivotCharts
- Interactive Dashboards

🔹 **1. Data Cleaning & Transformation | Power Query**

- Handled missing values and duplicate records.
- Checked and corrected data types.
- Separated raw data into Fact and Dimension tables.
- Prepared and structured data for analysis.

🔹 **2. Data Modeling | Power Pivot**

- Built a relational data model.
- Created Fact and Dimension tables.
- Established relationships using primary and foreign keys.
- Created a Date Dimension for time-based analysis.

🔹 **3. DAX Measures & KPIs**

Developed measures to analyze:

- Total Sales Excluding VAT
- Net Revenue
- Valid Orders
- Average Order Value (AOV)
- Units Sold
- Refund Amount & Refund Rate
- Year-to-Date Sales (YTD)
- Previous Year Sales (PY)
- Year-over-Year Growth (YoY)

🔹 **4. Dashboard Development**

Created two interactive dashboards:

📈 **Sales Performance Dashboard**
- Sales trends and year-over-year comparisons
- Sales by channel
- Sales by customer segment
- Order status distribution
- KPI performance tracking

📦 **Products & Returns Dashboard**
- Net revenue by product category
- Top 10 products by sales
- Refunds by product category
- Monthly refund trends
